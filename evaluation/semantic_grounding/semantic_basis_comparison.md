# NSM / Longman comparison for the six-concept probe

The six targets were checked against two explicit source lists on 2026-10-01.

| Target | NSM semantic prime? | Longman Defining Vocabulary? |
| --- | --- | --- |
| red | no | yes |
| object | no | yes |
| event | no | yes |
| support | no | yes |
| sit | no | yes |
| chair | no | yes |

Sources:

- NSM: *Chart of NSM Semantic Primes, English v20 (10 May 2022)*, https://nsm-approach.net/wp-content/uploads/2022/05/Chart-of-NSM-Semantic-Primes_English_v20_May-2022.pdf
- Longman Defining Vocabulary list, https://www.pu-kumamoto.ac.jp/users_site/rlavin/resources/wordlists/LDV.html

## Interpretation

**NSM non-membership** says only that the target is not one of the listed semantic primes. It does not establish the correct NSM explication, semantic-molecule status, or experiential grounding.

**Longman membership** says the word is admitted to a controlled defining vocabulary. It demonstrates practical definitional usefulness, not semantic primitiveness.

So the six targets instantiate three separate questions:

```text
Is it lexical-semantic primitive?        -> NSM prime status
Is it useful as a controlled definer?    -> Longman membership
Does it have a lower-level grounding?    -> Grounding IR path
```

The first two can be source-checked directly. The third is the research problem.

## Consequence

The specimen now records all six as:

- NSM: `not_prime`
- Longman: `defining_vocabulary_candidate`

This does **not** promote Longman words into Grounding IR primitives. `chair` is a useful counterexample: it is admitted to the defining vocabulary while remaining a high-level composed artifact concept in the grounding model.
